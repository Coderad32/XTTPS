  • Certificate‑like identity objects
  • Secure session orchestration
  • Multi‑language protocol handlers
  • Symbolic debugging overlays
  • A cross‑disciplinary toolkit for protocol research and field deployment

This repository serves as the core command module for your broader secure‑communication architecture.

Deployment

Clone the repository

git clone https://github.com/coderad32/XTTPS
cd XTTPS

Run the main command module

python Program.py

Launch the field‑test TCP server

perl TCP_Server.pl

Example operation: Secure session

from Context import Context
from Crypto_Msg import CryptoMessage

ctx = Context()
msg = CryptoMessage("UNSC Test Transmission")
signed = ctx.sign(msg)
verified = ctx.verify(signed)

print("Transmission Verified:", verified)
